## What agentic-OS IS

agentic-OS is **not built from scratch**. It is the **OS that integrates 47 existing repos** into a unified, self-sustaining system. It is the integration layer, not a new build.

## The Three Layers

**Ecosystem** — 47 repos providing all capabilities. 13 Tier-1: Aetheris, Nexus, Aetheris_Nexus, LocalForge, Guardian Mesh, A-HAIM, LLMVM, Argent, AxiomCode, agentic-OS, UIS, Zerok, PAE.

**Omega Code** — The builder. Orchestrates, verifies, and signs the ecosystem.

**Guardian Mesh** — The security fabric. ML-DSA-65 post-quantum crypto, 5-enclave firewall, formal verification, graduated containment. Every operation passes through Evaluate.

## Core Principle

**Integrate, don't rebuild.** Nothing external. Every line comes from the ecosystem.

## Self-Hosting Loop

Omega Code builds and improves the ecosystem. Guardian Mesh secures every action. The ecosystem provides all capabilities. No external CI, registries, or signing.

## Compliance

All 47 repos comply with SPDX and DCO. Every contribution signed, every build audited.

## One Rule

**Integrate, don't rebuild.** Wire it in or build it with the ecosystem. Nothing external.
