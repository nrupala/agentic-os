## Learning Commands

Paradise Stack provides commands for explicit learning:

### /learn-eval

Extract patterns from recurring interactions.

```
Usage: /learn-eval <pattern_description>
Example: /learn-eval "error handling in async functions"
```

### /evolve

Promote stable instincts to permanent skills.

```
Usage: /evolve <instinct_id>
Example: /evolve instinct_001
```

### /introspect

Review what Paradise Stack has learned.

```
Usage: /introspect
Shows:
  - Evolution level
  - Skills integrated
  - Patterns mastered
  - Knowledge age
```

## Knowledge Retention

Paradise Stack has **permanent memory** for:

| Knowledge Type | Retention Strategy |
|---------------|-------------------|
| Skills | Stored in skills catalog, indexed |
| Patterns | Master pattern catalog with usage tracking |
| Techniques | Structured storage, semantic retrieval |
| Instincts | Evolution log, confidence scoring |
| Preferences | Config files, persistent |

### Memory Layers

```
LAYER 1: Context Memory (Transient)
  └─ Active session
  └─ Current task state
  └─ Immediate context

LAYER 2: Knowledge Memory (Permanent)
  └─ Learned patterns
  └─ Extracted skills
  └─ Discovered techniques

LAYER 3: Project Memory (Static)
  └─ CLAUDE.md configuration
  └─ Team preferences
  └─ Project-specific rules
```

### Self-Healing Memory

Paradise Stack rewrites memory files when:
- Information becomes outdated
- Context changes significantly
- New patterns supersede old ones
- Errors are detected in stored knowledge

## Pattern Storage

Patterns are stored with metadata:

```json
{
  "pattern": "async_error_handling",
  "source": "collection-claude-code-source-code",
  "stars": 2100,
  "discovered": "2026-04-14T10:30:00Z",
  "usage_count": 0,
  "confidence": 0.95,
  "techniques": ["try_catch", "error_propagation", "retry_logic"]
}
```

### Pattern Matching

When given a task, Paradise Stack:

1. **Analyzes** the request
2. **Searches** pattern catalog for relevant patterns
3. **Ranks** patterns by confidence and usage
4. **Selects** best pattern for the task
5. **Executes** using selected pattern
6. **Updates** usage count on success

## Learning Best Practices

### For Maximum Growth

1. **Scan Regularly**: Run monthly GitHub scans
2. **Review Patterns**: Check pattern catalog periodically
3. **Use Commands**: Leverage /learn-eval and /evolve
4. **Provide Feedback**: Correct Paradise Stack when wrong
5. **Document Insights**: Share patterns that work well

## Troubleshooting Learning Issues

| Issue | Solution |
|-------|----------|
| No new patterns after scan | Check GitHub API rate limits |
| Low confidence patterns | Review and adjust pattern extraction |
| Skills not matching tasks | Improve semantic search keywords |
| Evolution stuck | Run manual /learn-eval commands |
