## How Learning Works

### 1. Monthly GitHub Scan
```bash
python tools/github_intelligence_scanner.py
```
- Searches for: SKILL.md, CLAUDE.md, agent prompts, patterns
- Filters: stars > 100 (minimum credibility threshold)
- Top 10 repositories integrated monthly

### 2. Pattern Extraction
```
Raw Content → Feature Extraction → Pattern Catalog → Master State
```
- Tools, techniques, approaches extracted automatically
- Patterns matched against existing knowledge
- New patterns added to master state

### 3. Evolution Integration
```python
from cognition.continuous_intelligence import evolve_with_scan
evolve_with_scan()
```
- New patterns update evolution level (1-10)
- Skills added to knowledge base
- Recommendations generated
